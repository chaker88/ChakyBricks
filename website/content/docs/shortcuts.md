# Keyboard shortcuts

The same list is in **Settings → Keyboard shortcuts** inside the app.

## Everywhere

| Keys | Action |
| --- | --- |
| ++ctrl+k++ | Open the command palette |
| ++ctrl+1++ | Go to Home |
| ++ctrl+2++ | Go to Catalog |
| ++ctrl+3++ | Go to SQL |
| ++ctrl+4++ | Go to Notebooks |
| ++ctrl+5++ | Go to Dashboards |
| ++ctrl+6++ | Go to Jobs |
| ++ctrl+7++ | Go to Settings |

## SQL editor

| Keys | Action |
| --- | --- |
| ++ctrl+enter++ | Run the selection, or the whole query |
| ++ctrl+shift+enter++ | Run all statements |
| ++ctrl+s++ | Save the query |
| ++ctrl+space++ | Show suggestions |

## Notebooks

| Keys | Action |
| --- | --- |
| ++shift+enter++ | Run the cell and move to the next one |
| ++ctrl+enter++ | Run the cell and stay |
| ++alt+enter++ | Run the cell and insert a new one below |

## Dashboards

| Keys | Action |
| --- | --- |
| ++ctrl+s++ | Save the dashboard (edit mode) |
| ++delete++ | Delete the selected tile (edit mode) |
| ++esc++ | Deselect the tile (edit mode) |
| ++ctrl++ / ++shift++ + click | Add to the cross-filter (view mode) |
